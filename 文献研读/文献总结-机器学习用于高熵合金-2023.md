## 论文详细总结

### 一、研究背景与动机

高熵合金 (HEAs) 自 2004 年由 Yeh [1] 和 Cantor [2] 两个研究组独立报道以来，因其卓越的力学性能和巨大的成分空间而受到广泛关注。与传统合金以单一基体元素为主不同，HEAs 将多种主元元素混合以形成单相随机固溶体。HEAs 的核心吸引力包括：(i) 优异的力学性能，如高温性能 [14]、低温下增强的强度-延展性-韧性组合 [15,16]、以及突破强度-延展性权衡的能力 [17,20,21]；(ii) 为研究化学有序/无序相关的变形机制提供了理想平台，包括短程序 (SRO) [27-29] 和长程序 (LRO) [30,31] 对位错核心结构和广义层错能的影响 [32-34]；(iii) 丰富且异质的微观结构，如层错多形态 [38]、孪晶结构 [22]、纳米析出相 [20,25] 等；(iv) 广阔的高维成分空间为材料设计提供了巨大潜力。

然而，HEAs 的高维化学复杂性给理论建模带来了独特挑战：(i) 经验原子相互作用模型的构建困难——对于 n 元体系，m 位交互作用数目正比于组合数 \(C(n,m)\)，五元体系仅考虑前四个配位壳层的对交互就有 40 种，传统簇展开方法 [41-43] 和嵌入原子法 (EAM) [44] 容易过拟合；(ii) 第一性原理模拟计算代价极高——HEAs 需要大超胞 (超过 1000 个原子) 来表示非化学计量比成分和复杂的有序-无序行为 [45,34]；(iii) 传统试错法材料设计对 HEAs 而言过于费力。

机器学习 (ML) 凭借其描述极复杂关系的能力，为解决上述问题提供了新范式。ML 模型的计算速度通常远快于 DFT 且接近经验势 [58-61]，使研究者能够以近 DFT 精度模拟超过百万原子的体系 [62,63]。

### 二、论文结构与核心内容

本文是一篇系统性综述，组织如下：

**第 2 节**介绍 ML 用于 HEAs 的一般工作流程，包括应用识别、数据收集、算法选择、模型训练和结果分析。

**第 3 节**讨论原子相互作用模型 (AIMs)，包括对称性保持描述符和四种主流 ML 势函数：高维神经网络势 (HDNNP)、高斯近似势 (GAP)、谱邻居分析势 (SNAP) 和矩张量势 (MTP)，以及有效刚性晶格哈密顿量。

**第 4 节**总结 ML 加速的原子尺度模拟进展，涵盖 Monte-Carlo (MC) 模拟、分子动力学 (MD) 模拟和混合 MC/MD 模拟。

**第 5 节**讨论宏观物理性质预测，包括固溶体/多相预测、ML 信息驱动的新相形成规则、基于神经网络的序参量、以及力学性质预测。

**第 6 节**讨论挑战与展望，包括模型置信度与不确定性量化、端到端描述符、以及 ML 引导的逆向材料设计。

### 三、核心理论贡献

1. **ML 势函数框架的系统比较**：论文系统比较了 HDNNP、GAP、SNAP、MTP 四种 ML 势函数的数学框架、对称性处理方式和适用场景，为 HEAs 研究者选择合适的势函数提供了清晰指导。

2. **数据驱动的簇展开方法**：针对传统簇展开在 HEAs 中面临的过拟合问题，论文介绍了正则化线性回归 (岭回归、LASSO)、贝叶斯信息准则 (BIC) 模型选择等数据驱动方法。

3. **ML 信息驱动的热力学规则**：Pei 等人 [48] 利用高斯过程分类 (GPC) 从 1252 个多元合金数据中提取了新的固溶体形成规则 \(\gamma \geq 1\)，该规则基于自由能而非传统的焓判据，整体 AUC 达到 0.97。

4. **基于 VAE 的序参量**：Yin、Pei 和 Gao [70] 提出了基于变分自编码器 (VAE) 的序参量来描述 HEAs 中的相变，该序参量在高温区与 LRO 一致，在低温区与 SRO 一致，展现了独特的物理内涵。

5. **ML 辅助的逆向材料设计**：论文展示了基于微观结构图像的神经网络逆向设计方法，通过复制回归模型的结构和参数并反转信息流，实现了从目标性能到合金成分的逆向设计。

### 四、主要研究案例概要

- **MC 模拟**：Liu 等人 [69] 研究了 MoNbTaW、MoNbTaVW、MoNbTaTiW 三种难熔 HEAs 的有序-无序转变，识别了两个转变温度 \(T_1\) 和 \(T_2\)，预测 MoNbTaW 在 1000-2000 K 范围内比 MoNbTaVW 更具延展性，与实验吻合。
- **MD 模拟**：Jafary-Zadeh 等人 [173] 用 MTP 分离了 CoFeNi 中局部晶格畸变的静态、动态、热膨胀和 CSRO 贡献；Gubaev 等人 [174] 用 MTP 研究了 TiZrHfTa 的弹性常数。
- **混合 MC/MD**：Ong 等人 [65] 用 SNAP 计算了 MoNbTaW 的 GSFE (36000 原子超胞)，测定螺位错 Peierls 应力为 1620±637 MPa，刃位错为 320±113 MPa；Yin 等人 [64] 用 MTP 在 573672 原子超胞中研究了 CSRO 对位错迁移率的影响。
- **相预测**：Zhang 等人 [134] 用遗传算法从 45 个 ML 模型中筛选最优模型，固溶体识别准确率 88.7%，晶体结构预测准确率 91.3%；Lee 等人 [132] 用 GAN 数据增强将 DNN 相预测准确率从 84.75% 提升至 93.17%。
- **力学性质**：Pei 等人 [50] 用 GPC 识别了 Mg 合金延展性增强的描述符，与两种已知机制高度一致；Zheng 等人 [184] 用 ANN 设计了屈服强度 1.31 GPa、拉伸延伸率 15% 的 HEA。

### 五、挑战与展望

1. **模型置信度**：需要不确定性量化 (UQ) 来判断 ML 预测的可靠性，方法包括 Dempster-Shafer 证据理论 [72]、贝叶斯方法 [219]、概率箱 [220]、多级/多保真/多模型 Monte-Carlo 方法 [223-228] 等。
2. **高效学习物理**：手工设计的对称性保持描述符虽成功，但端到端方案 (如图神经网络 GNN) 更具广泛适用性，但需要更大的训练数据集 [209]。
3. **高质量数据集**：HEAs 的小数据问题比其他材料更严重；需要鼓励发表负面结果、报告测量细节、进行数据清洗和校准。
4. **逆向材料设计**：ML 可以从微观结构图像和性能数据中实现逆向设计，但仍处于起步阶段。

## 全文翻译

### 1. 引言

#### 1.1 高熵合金

传统的合金化策略是向一种主要金属中添加少量性能增强元素。人类使用这一技术已有数千年历史，历史上一些最广泛使用的材料即为范例，如青铜、钢和铝合金。然而，2004 年单相多组元高熵合金 (HEAs) 的发现 [1,2] 引入了一种不同的合金化策略。传统合金由一种基体元素和少量浓度低得多的附加元素组成，而在 HEAs 中，多种主元元素被混合以获得单相随机固溶体。这些新型材料被命名为 HEAs [1,3]，因为其被认为具有增强的构型熵，而构型熵被认为是其稳定化的原因。然而，构型熵的作用并不总是如最初假设的那样重要 [3-5]，因此多组元合金、多主元合金、成分复杂合金或复杂浓缩合金等名称也被广泛使用 [6]。这种混合多种主元元素的新策略打开了探索化学成分图角落之外的广阔未知空间的大门。HEAs 已成为材料科学中最令人兴奋的研究方向之一，具有前所未有性能的 HEAs 不断涌现，如图 1 所示。由于已有许多优秀的 HEAs 综述论文 [7-13]，我们无意重述其中的细节，这也不是本工作的主要关注点。

几个关键因素促成了人们对 HEAs 的巨大兴趣。第一个是其卓越的力学性能，如优异的高温性能 [14]、低温下增强的强度、延展性和韧性 [15,16]，以及最重要的强度与延展性的优异组合 [2,17-26]。一些 HEAs 展示了克服强度-延展性权衡的非凡能力 [17,20,21]。另一个原因是 HEAs 还为研究与化学有序和无序相关的变形机制提供了一个有吸引力的平台。多种主元元素对晶格位点的不同占据产生了不同程度的随机性和有序性，以短程序 (SRO) [27-29] 和长程序 (LRO) 参量 [30,31] 来表征，这些对塑性变形至关重要的物理量有显著影响，如位错核心结构和广义层错能 [32,33],[34]。调节有序和无序程度可以改善 HEAs 的力学性能 [35,36,27-29],[37]。第三个原因是其多样且异质的微观结构，如层错的多形态 [38]、孪晶结构 [22]、Shockley 不全位错与层错的解耦 [39]、纳米尺度相 [17]、超细晶层状结构 [19] 和纳米析出相 [20,25,21,40]。虽然这些微观结构也可以出现在传统合金中，但 HEAs 中大量的元素为调节它们提供了更多的自由度。高可调性有利于增强单相随机 HEAs 的力学性能。最后但同样重要的是，HEAs 广阔的高维成分空间中几乎未被探索的非等原子比浓度，展示了材料设计的巨大潜力。

#### 1.2 高熵合金建模中的挑战

虽然增加的主元元素为合金设计带来了巨大机遇，但它们也给理论建模和模拟引入了重大挑战。第一个挑战是构建经验原子相互作用模型的困难，主要由于涉及的大量化学交互作用。例如，对于 n 元体系，m 位交互作用的数目正比于

$$C(n,m) = \frac{n!}{m!(n-m)!} = \frac{n(n-1)\cdots(n-m+1)}{m(m-1)\cdots 1}$$

对于五元体系，仅考虑前四个配位壳层内的对交互作用就已经给出 $4×C(5,2)=40$ 种不同的交互作用。考虑高阶交互作用将大幅增加交互作用数目，使得传统的簇展开方法 [41-43,31] 和嵌入原子法 (EAM) [44] 容易过拟合。第二个挑战出现在第一性原理模拟中。众所周知，密度泛函理论 (DFT) 模拟通常计算代价高昂。然而，对于 HEAs，由于需要使用大超胞 (多达超过 1000 个原子) 来表示非化学计量比成分、复杂的有序-无序行为、微观结构和扩展的位错核心结构 [45],[34]，DFT 模拟更加令人望而却步。对于第一性原理热力学模拟，计算代价更为苛刻，因为必须评估许多构型，每个构型都需要昂贵的 DFT 计算。例如，对于 250 原子的 CuZn 超胞，第一性原理 Monte-Carlo 模拟需要 600000 次 DFT 能量的自洽 (SCF) 计算 [46]，这可以轻松消耗一百万 CPU 核时。最后，传统的试错法材料设计对 HEAs 而言过于费力，因此非常需要替代模型来指导广阔成分空间的高效探索，如相形成规则 [47],[48]、强化模型 [44,49] 和延展性判据 [50],[51,52]。然而，由于涉及的大量化学物种，这些经验规则对 HEAs 而言难以建立。

#### 1.3 机器学习用于高熵合金的优势

过去十年见证了机器学习 (ML) 及其子领域深度学习的爆发式崛起 [53]。这场革命不仅从根本上改变了计算机科学的几个领域，如计算机视觉和自然语言处理，还改变了从粒子信号检测 [54]、蛋白质结构预测 [55]、医学图像分析 [56] 到宇宙巡天 [57] 等众多科学领域。ML 的成功在于其描述复杂模式的能力，这些复杂的 ML 模型可以通过从数据中学习来系统地优化。这种能力进一步得益于现成的计算资源、高效的算法和从实验或计算中收集的大数据。这些特征使 ML 成为解决 HEAs 理论建模所面临上述挑战的有前途的工具。相关出版物的指数增长反映了这一趋势 [见图 1b]。原则上，给定足够大的高质量数据，复杂的原子交互作用可以通过训练、验证和测试的标准程序被 ML 很好地捕获。

此外，ML 模型的计算速度通常远快于 DFT 且接近经验势 [58-61]。这种高效率使研究者能够以近 DFT 精度模拟超过百万原子的材料 [62,63]，远超传统 DFT 的极限。这种能力对于理解 HEAs 中源于复杂有序、缺陷和微观结构的非凡力学性能尤为重要 [64,65]，这些需要精确的纳米尺度模拟。除模拟外，ML 还为材料性质预测模型的构建提供了强大工具。通过从数据中学习，ML 可以自动识别实现所需物理性质所必需的特征或潜变量。这些复杂的非线性结构-性质关系难以通过人类观察来建立。识别它们使研究者能够更高效地探索 HEAs 的巨大设计空间。ML 的上述优势为 HEAs 研究引入了新的数据驱动范式 [66,67]，如其在原子尺度模拟 [68-70]、物理性质预测 [48],[71] 和材料设计 [72-74] 中的成功所展示。

#### 1.4 本综述的独特性与结构

本综述聚焦于 ML 在高熵合金 (HEAs) 中的应用。虽然已有几篇关于 ML 用于材料科学更广泛主题的优秀综述 [75-80,67,66]，但缺乏对 ML 用于 HEAs 的激动人心的进展和巨大潜力的全面综述。具体而言，

- 我们对 ML 用于 HEAs 这一跨学科主题进行了全面综述，启发式地讨论了基本方法和模型，并总结了重要应用以说明 ML 对 HEAs 的优势；
- 我们识别了 HEAs 理论建模中的挑战，并从微观和宏观两个角度说明了 ML 如何帮助解决这些问题；
- 我们比较了不同 ML 方法对 HEAs 的优势和不足，总结了 ML 方法的剩余挑战，并讨论了伴随这些挑战的未来机遇。

本综述组织如下：首先，给出 ML 用于 HEAs 的引言，包括应用识别、数据生成、常见算法、模型训练和结果分析。接下来，讨论用于原子尺度模拟的流行 ML 势函数。以下三节聚焦于将 ML 应用于 HEAs 的最新进展，包括原子尺度模拟、性质预测和材料设计。最后，在展望部分讨论 ML 用于 HEAs 的挑战和机遇。

### 2. 如何利用机器学习研究高熵合金？

ML 模型的一般工作流程如图 2 所示。虽然 ML 通常是一种通用且强大的工具，但应记住它只在某些特定子集的问题上表现出色。具体而言，ML 对具有丰富高维数据和明确定义目标的问题最为有效。因此，利用 ML 研究 HEAs 的第一步是应用识别 [81]，即确认问题可以转化为 ML 问题。之后，应选择适当的 ML 算法来解决特定的 ML 问题。数据被收集并通常分为三个子集，即 (i) 用于模型训练的训练集，(ii) 用于模型选择的验证集，和 (iii) 用于模型性能评估的测试集。最后，训练良好的 ML 模型应捕获底层物理。性能良好的模型使得通过直接检查其参数或通过降维技术 [82] 来提取知识成为可能。

#### 2.1 应用识别

HEAs 最常见的 ML 应用之一是构建代理模型。代理模型用于在实际关系未知或难以推导时近似建模一组输入-输出数据。目前，这些代理模型的应用大致可分为 (i) 原子尺度上的原子尺度模拟和 (ii) 宏观尺度上的物理性质预测。这里我们将相应的 ML 模型分别称为原子相互作用模型 (AIMs) 和体性质模型 (BPMs)。两种应用对比如表 1 所示。具体而言，AIM 和 BPM 从不同的时间和长度尺度处理材料科学问题。AIM 遵循第一性原理方法的精神。然而，与 DFT 中的亚原子电子和原子核不同，AIM 的输入特征是不同原子的排列。用重整化群的语言来说，电子自由度已被"积掉"。与 BPM 相比，AIM 的一个主要优势是其高可迁移性。训练良好的 AIM 可用于评估许多不同的物理量，如形成能、弹性常数、层错能和声子谱 [59,60]。相比之下，BPM 的优势在于它直接预测目标物理性质而无需昂贵的模拟。AIM 和 BPM 之间的另一个关键区别是保真度要求：AIMs 通常对模型预测的精度要求高于 BPMs。例如，分子动力学中一步的非物理力预测可能导致所有后续模拟完全错误的轨迹。因此，将物理信息融入 AIMs 非常重要，如材料底层的平移、旋转和置换对称性。

除构建代理模型外，ML 还可用于从大量数据中获取物理洞察。为此，降低数据维度和提取重要特征至关重要，因为物理规则在低维空间中更为明显。对于某些 ML 模型，如决策树和浅层神经网络 [83,84]，可以通过检查模型的权重参数来识别重要特征。无监督学习也是提取隐藏物理的广泛使用技术。无监督学习不需要劳动密集型的数据标注，这是其独特优势之一。相反，它探索未标注数据集中的模式和结构。无监督学习的一个典型例子是聚类，它根据数据在特征空间中的相似性将数据分为若干组。另一个优秀的例子是变分自编码器 (VAE) [86]。它可以显著减小数据规模，同时仅在极少数维度 (通常为两个) 的潜空间中保留基本信息。借助 VAE 的这一优势，Yin、Pei 和 Gao 提出了一种基于 VAE 的序参量来描述 HEAs 中的相变 [70]。

#### 2.2 代表性机器学习算法

不同的 ML 算法有不同的优势和不足。因此，根据任务目标和数据集大小选择适当的算法至关重要。

**神经网络 (NN)**：神经网络，也称为人工神经网络 (ANNs)，是深度学习算法的骨干 [88,89]。神经网络由多个函数层组成，每层由多个神经元组成。神经元接收来自前一层的输入，将其与权重参数相乘 (点积)，加上偏置项，然后将结果传递给激活函数以产生输出。NNs 通常用随机梯度下降 (SGD) 算法优化，其中反向传播方法常用于更新模型参数，以最小化给定数据样本的损失函数。

**支持向量机 (SVM)**：SVM 是一种广泛使用的用于分离不同组数据的算法 [93]。SVM 的原理是找到一个最大化两组之间间隔的超平面。在线性 SVM 中，最大化间隔的决策平面 $w^T x + b = 0$ 通过在约束 $y_i(w^T x_i + b) \geq 1$ 下最小化 $\|w\|$ 来给出。SVM 还可以通过使用核方法扩展到非线性情况。核的一个常见选择是径向基函数 (RBF)。

**高斯过程 (GP)**：GP 基于贝叶斯定理，即后验正比于先验和似然的乘积 [94]。GP 最具吸引力的特征是它可以估计模型参数的概率分布，这使得不确定性量化变得直接 [95]。另一方面，高斯过程对于大数据集 (>10000 个数据点) 通常计算代价高昂。

**分类与回归树 (CART)**：决策树是一种直观且易于解释的方法 [97]。一个广泛使用的度量是 Gini 不纯度，定义为 $G = 1 - \sum_i p_i^2$。当每个决策树使用随机特征集进行分割时，这种方法称为随机森林 (RF) [98]。更强的预测器也可以通过提升 (boosting) 获得 [99]。

#### 2.3 数据收集

##### 2.3.1 原子尺度模拟的数据

训练数据集通常通过 DFT 计算获得。ML 模型的高质量训练数据集应该是均匀的、足够大的和具有代表性的。线性标度 DFT 方法可用于提高 DFT 计算的效率。线性标度 DFT 利用近视原理 [100] 将计算复杂度从 \(O(N^3)\) 降低到 \(O(N)\)。例如，局部自洽多重散射 (LSMS) 方法 [102,103] 被 Liu 等人 [104,105,68,69] 用于加速 HEA 数据集的计算。

##### 2.3.2 物理性质模型的数据

预测体物理性质的 ML 模型的训练数据有多种来源，包括实验数据库 (Pauling File [106]、MEAD [107]) 和计算数据库 (Materials Project、OQMD [109]、AFlow [110]、NOMAD、AiiDA [112])。也有专门针对 HEAs 的已发表数据源，如 Senkov 和 Miracle 等人编辑的数据库 [114,115]，以及 Gao 等人发表的 1252 条数据 [117]。

##### 2.3.3 数据增强

主动学习常用于通过从模拟中纳入重要数据点来迭代改善数据集质量 [122,123]。扩展数据集的另一种方法是生成对抗网络 (GAN)。例如，Lee 等人 [132] 使用 GAN 增强 HEA 性质数据集，将深度神经网络模型的相预测测试准确率从 84.75% 提升至 93.17%。

#### 2.4 模型选择

相预测常用的描述符包括原子序数、原子尺寸、混合熵、混合焓、电负性、价电子浓度、弹性常数、熔点温度等。特征选择技术有三类：相关性度量、正则化技术 (如 LASSO)、以及暴力搜索。超参数选择包括基于信息准则 (BIC、AIC) 的方法和基于留出样本 (交叉验证) 的方法。

#### 2.5 模型训练

ML 模型通过损失函数的最小化来确定参数。均方误差 (MSE) 损失函数为：

$$\text{MSE} = \frac{1}{N_{\text{config}}} \sum_{k=1}^{N_{\text{config}}} (E^{k,\text{ML}} - E^{k,\text{DFT}})^2 + w_F \sum_{k=1}^{N_{\text{config}}} \sum_{i=1}^{N_k} (F_i^{k,\text{ML}} - F_i^{k,\text{DFT}})^2$$

其中 \(N_{\text{config}}\) 是数据集中构型的数目，\(N_k\) 是第 k 个构型超胞中的原子数目，\(w_F\) 是原子力的权重因子。

#### 2.6 结果分析

对于分类任务，召回率、精确率、AUC 或 ROC 曲线常用于衡量模型性能。对于回归任务，RMSE 和 \(R^2\) 分数被广泛使用。深度神经网络由于其非线性和高维度通常难以解释。t-SNE 算法 [142] 是可视化高维数据的一个重要技术。

### 3. 原子相互作用模型

原子相互作用模型的一个重要要求是它们应该与体系大小无关；因此，从小体系训练的模型可以用于研究大得多的体系。为此，原子能量 \(E_i\) 是一个关键量，它代表单个原子的能量贡献：

$$E = \sum_{i=1}^{N_{\text{atom}}} E_i(\sigma_i) + E_0$$

其中 \(\sigma_i = \{\sigma_i^0, \sigma_i^1, \sigma_i^2, \cdots \sigma_i^{N_n}\}\) 代表第 i 个原子的原子环境，\(\sigma_i^0 = (z_i, r_i)\) 代表第 i 个原子的原子种类和位置，\(\sigma_i^{j \neq 0} = (z_j, r_{ij})\) 代表截断半径 \(r_c\) 内的周围 \(N_n\) 个原子。\(E_0\) 代表仅依赖于化学浓度而不依赖于原子排列的长程静电项。因此，建立构型与总能量之间映射的问题被简化为将原子的局部环境映射到其原子能量，如图 3 所示。

#### 3.1 对称性保持描述符

需要设计一种保持底层对称性的编码方案来高保真地表示原子环境。作为分类变量，原子种类可以用独热编码、元素嵌入 [143,70] 或简单地为每个原子种类分配唯一权重来表示。笛卡尔坐标不能直接用作特征，因为将位置压缩为一维向量会完全失去系统的底层对称性。一个著名的例子是 Parrinello-Behler 描述符 (也称为对称函数)，它使用高斯函数和截断函数的乘积来表示原子的径向排列，采用 \(\cos(\theta_{ijk})\) 函数来描述角度分布 [145,146]。其他对称不变量也可以用来表示化学构型，如功率谱和双谱 [147,144]，以及矩张量 [148,131]。

#### 3.2 机器学习势函数

与传统势相比，ML 势有两个主要特征：首先，ML 势采用灵活而非固定的函数形式，其精度可以系统地提高；其次，ML 势采用由训练、验证和测试组成的数据驱动方法。以下简要介绍四种常用的 ML 势。

##### 3.2.1 高维神经网络势 (HDNNP)

人工神经网络 (ANN) 被广泛用于建立原子环境与原子能量之间的非线性映射。通常使用前馈多层感知器 (MLP)。一个简单的全连接层为

$$Y = \phi(WX + b)$$

其中 X 是输入向量，b 是偏置向量，W 是权重矩阵，$\phi$ 代表激活函数，Y 是输出向量。由于神经网络应用于每个原子，NNP 也被称为高维 NNP (HDNNP) [146]。具有不同 \(\{W, b\}\) 参数集的神经网络用于表示各个原子种类，但给定原子种类的原子神经网络是相同的。不同的原子能量归因于原子的不同环境。

##### 3.2.2 高斯近似势 (GAP)

在 GAP [147,144,155,156] 中，总能量通过高斯过程回归 (GPR) 方法预测，该方法衡量原子环境与参考的"相似性" [157]。GAP 的计算复杂度随数据点数目 N 立方标度，可以通过使用稀疏 GP (仅使用 M 个诱导点，\(N \gg M\)) 来缓解。原子环境 \(\sigma_i\) 可以用原子邻居密度来表示：

$$\rho_i(\mathbf{r}) = \sum_j w_{Z_i} f_{\text{cut}}(r_{ij}) \exp\left(-\frac{|\mathbf{r} - \mathbf{r}_{ij}|^2}{2\sigma_{\text{atom}}^2}\right)$$

使用上式，SOAP 核通过对原子 i 和 s 的邻居密度的平方重叠在所有可能的三维旋转上积分来获得 [157]：

$$\tilde{K}(\sigma_i, \sigma_s) = \int_{\hat{R} \in SO(3)} d\hat{R} \int d\mathbf{r} \, \rho_i(\mathbf{r}) \, \rho_s(\hat{R}\mathbf{r})^2$$

在实践中，三维旋转通过将原子密度展开为球谐函数来解析完成，其积分可以用 Clebsch-Gordan 系数表示。

##### 3.2.3 谱邻居分析势 (SNAP)

SNAP 与 GAP 密切相关，其核心量也是原子邻居密度。用球谐函数作为基组展开密度，展开系数为

$$c_{ilm} = \sum_{j: r_j < r_c} Y_{lm}(\hat{r}_j)$$

最简单的旋转不变量是功率谱

$$p_{il} = \sum_{m=-l}^{l} c_{ilm}^* c_{ilm}$$

更复杂的不变量如双谱可以使用径向分布函数来构建，并将 \(r_c\) 内的原子邻居密度映射到四维空间中的球面上 [153]。功率谱和双谱可以用作各种回归模型的描述符，包括线性 SNAP [153]、二次 SNAP (qSNAP) [154] 和谱神经网络势 [159]。

##### 3.2.4 矩张量势 (MTP)

MTP 使用矩张量的缩并来构建不变描述符。在 MTP 中，总能量表示为

$$E = E_0 + \sum_{i=1}^{N_{\text{atom}}} \sum_{\alpha} \xi_{\alpha} B_{\alpha}(\sigma_i)$$

基函数 \(B_{\alpha}\) 用矩张量描述符定义：

$$M_{\mu,\nu}(\sigma_i) = \sum_j f_{\mu}(r_{ij}, z_i, z_j) \underbrace{r_{ij} \otimes \cdots \otimes r_{ij}}_{\nu \text{ times}}$$

径向函数 \(f_{\mu}\) 用截断函数和 Chebyshev 多项式展开。张量部分包含原子环境的角度信息。MTP 参数 \(\theta = \{\xi, c\}\) 通过最小化训练数据集的损失函数来确定。

#### 3.3 有效刚性晶格哈密顿量

在刚性晶格模型中，总能量可以用簇交互作用展开：

$$E = E_0 + \sum_{\alpha} V_{\alpha} \phi_{\alpha}(\Sigma)$$

其中 \(\phi_{\alpha}\) 代表簇 \(\alpha\) 的相关函数，\(V_{\alpha}\) 是有效簇交互作用 (ECIs)。传统簇展开已被 HEAs 所挑战，因为大量的交互作用容易过拟合 [163,164,31]。数据驱动方法通过正则化线性回归来确定 ECIs：

$$\hat{V} = \arg\min_V \|E - \phi V\|_2^2 + g(V)$$

常用岭正则化 \(g(V) = \lambda \|V\|_2^2\) 或 LASSO 正则化 \(g(V) = \lambda \|V\|_1\)。Zhang 等人 [68] 提出使用贝叶斯信息准则 (BIC) 进行特征选择：

$$\text{BIC}_{\text{RSS}} = n_d \log\left(\frac{\text{RSS}}{n_d}\right) + k \log(n_d)$$

对于非线性效应，Natarajan 和 Van der Ven [166] 使用神经网络来建模有效原子交互作用，总能量写为

$$E = E_0 + \sum_i E_i(G_i^{\alpha}, G_i^{\beta}, \cdots)$$

对于六个局部特征，NN 模型的测试误差为 0.006 eV/atom，而线性模型为 0.014 eV/atom。

### 4. 机器学习加速的原子尺度模拟

本节总结了使用 ML 代理模型加速基于 DFT 的原子尺度模拟的进展。这些模拟可分为三类：Monte-Carlo 模拟、分子动力学和混合 MC/MD 模拟。Monte-Carlo 模拟的主要优势是原则上可以覆盖整个相空间，这对研究不同温度下的化学短程序 (CSRO) 和相演化至关重要。Monte-Carlo 方法的一个主要局限是不能描述非平衡动力学过程。分子动力学擅长研究原子运动，但由于有限的时间尺度，通常只模拟相空间的一小部分。混合 MC/MD 通过在 MD 模拟中引入 MC 交换步骤来增加访问的相空间。

#### 4.1 Monte-Carlo 模拟

HEAs 大多数迷人的力学性能可以追溯到化学有序和无序的复杂相互作用。在一阶近似下，随机 HEAs 可以被视为由完美晶体组成，每个位点被主元元素之一随机占据。对这种简单近似的第一个修正是局部晶格畸变。另一个重要的修正是样品中的短程序和长程序。当 HEAs 从熔化温度冷却时，具有有利键合能的原子对倾向于更频繁地出现，产生不同程度的有序。这些不均匀性阻碍位错的运动，可以对强度和延展性产生深远影响。

Liu 等人 [69] 使用正则 MC 模拟研究了三种难熔 HEAs：MoNbTaW、MoNbTaVW 和 MoNbTaTiW。MC 模拟由有效对交互作用 (EPI) 模型提供信息，采用贝叶斯信息准则 [68] 进行模型选择。他们发现该方法产生了高精度的哈密顿量，所有三种 HEAs 的误差棒小于 0.1 mRy。对于三种 HEAs 中的每一种，从计算的比热和 SRO 参数中识别了两个有序-无序转变温度 \(T_1\) 和 \(T_2\)，如图 5 所示。计算表明 MoNbTaW 的有序-无序转变温度远低于 MoNbTaVW，因此在 1000 K 到 2000 K 的范围内，MoNbTaW 主要是固溶体，而 MoNbTaTiW 应包含大量的第二相析出，即 MoNbTaW 预计比 MoNbTaVW 更具延展性，这已被实验结果证实。

LRP 也被应用于计算几种 BCC 和 FCC 多组元合金的热力学。Kostituchenko 等人研究了 MoNbTaW [168]、BCC AlNbTiV [170] 和 FCC VCoNi [169] 中的有序-无序转变。对于 VCoNi，他们发现约 1500 K 的有序-无序转变。他们还发现忽略晶格弛豫可以使预测的转变温度增加超过 30%。Shapeev 等人将 LRP 应用于 FCC NiCoFeCr HEA [171]，发现 Fe 和 Cr 分别在低于 600 °C 和 1230 °C 的温度下形成亚晶格。

#### 4.2 分子动力学模拟

Jafary-Zadeh 等人 [173] 通过 MTP 信息驱动的 MD 模拟研究了 CoFeNi 基合金中的局部晶格畸变 (LLD) 效应，成功分离了 LLD 的静态、动态、热膨胀和 CSRO 贡献。Gubaev 等人 [174] 用 MTP 研究了 TiZrHfTa 的弹性常数，发现结构相变可以深刻影响弹性性质。HDNNP 也被应用于研究 VZrNbHfTa 熔体 [175]，AIMD 和 HDNNP 结果之间有良好的一致性。

#### 4.3 混合 MC/MD 模拟

广义层错能 (GSFE) 是描述塑性变形行为的关键量，它决定了位错的核心结构和 Peierls 应力。Ong 等人用 SNAP 模型信息驱动的混合 MC/MD 模拟研究了 MoNbTaW 中的强化机制 (图 6) [65]。GSFE 用包含 36000 个原子的大超胞计算。Peierls 应力值为螺位错 1620±637 MPa，刃位错 320±113 MPa。Yin 等人 [64] 用 MTP 在 573672 个原子的巨大超胞中研究了 CSRO 对位错迁移率的影响。

Hodapp 和 Shapeev 用 MTP 计算了 Mo-Nb-Ta 合金的不稳定 SFEs [176]，与 DFT 极好一致 (最大相对误差 6-7%)，且 DFT 训练数据可从约 10000 量级减少到约 50-100。Curtin 等人使用 HDNNP 研究了 Al-Cu [177]、Mg 合金 [181] 和 Al-Mg-Si [182] 的位错和 GSFE。Byggmästar 等人 [172] 开发了 MoNbTaWV 的 GAP 势，研究了辐射损伤效应。

纯金属方面，Dragoni 等人用 GAP 计算了 BCC 铁的 GSFE [178]，Maresca 等人研究了 BCC 铁的位错核心 [179] (Peierls 应力约 2 GPa)，Wang 等人用 SNAP 研究了 Mo、Ta、Nb、W 的 GSFE 和 Peierls 应力 [180]。

### 5. 物理性质预测

#### 5.1 固溶体和多相的预测

热力学决定合金中的相，这为设计高性能合金 (包括 HEAs) 提供了必要信息。通常，我们需要预测给定合金成分的相。其逆问题，即识别满足特定目标的合金成分 [194]，更令人感兴趣。HEAs 的广阔成分空间在很大程度上未被探索，已合成的 HEAs 只是字面上不可计数的 HEAs 中的极小部分。

Zhang 等人进行了涉及许多描述符和 ML 算法的综合研究，共制作了 45 个 ML 模型 [134]。使用遗传算法 (GA)，优化后的模型在识别固溶体和非固溶体相方面达到 88.7% 的准确率，在预测 BCC、FCC 和双相 HEAs 方面达到 91.3% 的准确率。Huang 等人比较了 KNN、SVM 和 ANN 模型 [186,187]，ANN 模型最准确 (74.3%)。Lee 等人用深度神经网络和 GAN 数据增强 [132]，优化后的模型达到 84.75% 的准确率。Kaufmann 等人评估了随机森林的性能 [83]。Li 等人 [188] 使用 SVM 来区分不同的晶体结构。

#### 5.2 机器学习信息驱动的相预测新规则

ML 还可以提供关于元素在相形成中作用的物理洞察。我们提供一个详细的例子来展示如何使用 ML 来改善 HEAs 热力学性质的预测 [48]。我们采用高斯过程分类 (GPC) 算法，收集了 1252 种多组元和二元合金。特征基于 85 种元素性质构建 [196]。GPC 模型的整体 AUC 达到 0.97，验证准确率为 93%。

ML 结果显著改善了基于形成焓 \(\Delta H\) 的传统标准。固溶体的有利能量窗口为 \(\Delta H \in [-16.25, 5]\) kJ/mol，但这个经验规则不准确。通过 ML 识别的最相关物理性质，我们发现固溶体具有 \(\gamma \geq 1\)，其中 \(\gamma\) 定义为

$$\gamma := \begin{cases} \Delta G_N / \min(\Delta G_2) & \text{if } \min(\Delta G_2) < 0 \\ -\Delta G_N / \min(\Delta G_2) & \text{if } \Delta G_N < 0 \text{ and } \min(\Delta G_2) > 0 \end{cases}$$

\(\Delta G\) 是多组元和二元合金的自由能。规则 \(\gamma \geq 1\) 与晶格畸变 \(\delta\) 参数一起给出 75% 的整体准确率。该规则虽然精度较低，但在物理上更透明，便于高通量筛选。

#### 5.3 基于机器学习的序参量

序参量用于描述材料的相态，是凝聚态物理和材料科学的核心概念之一 [197-199]。Yin、Pei 和 Gao [70] 提出了基于变分自编码器 (VAE) 的序参量 (图 9)。VAE 的编码器和解码器都由几个三维卷积层和平均池化层的复合层组成。潜变量 z 从均值为 \(\mu\)、标准差为 \(\sigma\) 的高斯分布中采样。

VAE 序参量使用 Manhattan 距离定义：

$$\langle Z_{op} \rangle_T = \frac{1}{M} \sum_{X_j \in T} \sum_i^d |z_i(X_j)|$$

VAE 磁化率从 \(Z_{op}\) 计算：

$$\chi(Z_{op}) = N\left(\langle (Z_{op})^2 \rangle_T - (\langle Z_{op} \rangle_T)^2\right)$$

VAE 磁化率正确地发出了 HEAs 相变温度的信号。VAE 序参量在高温区与 LRO 参数高度一致，在低温区与 SRO 参数更一致，表明它不是经典序参量的简单代理，而具有独特的物理特征。

#### 5.4 力学性质预测

ML 算法可以高效地识别力学性能的描述符。Pei 等人 [50] 以二元 Mg 合金为例，采用 GPC 算法，考虑所有可用的 85 种元素性质并暴力筛选与延展性最相关的性质。ML 预测与两个已知的延展性增强机制 (非基面位错形核机制 [205] 和非基面位错迁移率机制 [206]) 高度一致。

Rickmann 等人 [71] 用 CCA 和遗传算法识别了对 HEAs 硬度有贡献的重要特征。Wen 等人 [192] 构建了多个 ML 模型来估计硬度，合成了硬度比训练数据集中最佳合金高 10% 的合金。Peng 等人 [193] 成功预测了高温多组元钢的屈服强度。Bhandari 等人 [202] 用随机森林预测了 MoNbTaTiW 和 HfMoNbTaTiZr 的屈服应力。Zheng 等人 [184] 用 ANN 设计了屈服强度 1.31 GPa、拉伸延伸率 15% 的 HEA。Kim 等人 [183] 对 FCC HEA AlCoCrFeNi 的弹性常数进行了详细计算。

### 6. 挑战与展望

#### 6.1 挑战

尽管 ML 对 HEAs 有优势，但仍需要解决挑战以充分发挥其潜力。第一个是模型置信度，即理解模型何时给出准确预测以及何时可能不准确。没有这样的知识，信任 ML 模型的预测将非常冒险，如一些著名的"对抗攻击"例子所示 [208]。标准工具是不确定性量化 (UQ)。还希望对各种 ML 势和模型进行客观、广泛的基准测试 [59,61,60,209],[210]。

另一个挑战是高效地学习底层物理。目前最流行的方法是使用手工设计的对称性保持描述符。端到端方案 (如图神经网络 GNN) 更具广泛适用性，但需要更大的数据集 [209]。参考文献 [209] 证明一系列 GNN 方法需要一到两个数量级更大的数据集才能获得与描述符方法相似的精度。

第三个挑战是获得高质量数据集。实验和模拟数据面临不同研究组在不同条件下测量的问题。HEAs 的小数据问题比其他材料更为严重。研究者应被鼓励发表负面结果以及正面结果 [212]。对于小数据集，线性回归和 SVM 预计比深度神经网络表现更好。报告测量细节以促进数据在 ML 中的使用也很重要。

#### 6.2 不确定性量化

ML 算法通常被用作"黑箱"方法，因此进行 UQ 以确定预测的可靠性至关重要 [213]。Ha 等人 [72] 开发了基于 Dempster-Shafer (DS) 证据理论的 HEA 推荐系统 (ERS)。其他 UQ 方法包括模糊集 [216]、区间方法 [217]、信息理论 [218]、贝叶斯方法 [219] 和概率箱 [220]。Zhang 和 Shields [221] 提出了统一的贝叶斯框架。现代 Monte-Carlo 方法包括多级 [223-225]、多保真 [226,227] 和多模型 [228] Monte-Carlo 方法。通过识别和量化不确定性来源，可以绘制模型预测的置信区间，并促进主动学习 [231,232]。

#### 6.3 端到端 (自动学习的) 描述符

基于卷积神经网络 (CNN) 的模型，如图卷积神经网络 (GCNN) [234-236] 和三维 CNN [237,238]，原则上可以自动找到重要特征。GCNN 使用图结构数据而非二维或三维网格来表示原子排列，通过保持原子和化学键的概念展示了出色的可解释性 [235,239]。已提出不同的 GCNN 模型，如 SchNet [240]、MEGNet [241]、DimeNet [242] 和 GemNet [242]，其实现可在 PyTorch Geometric 包中找到 [243]。然而，GCNN 在 HEAs 原子尺度模拟中的采用很少，因为它们容易过拟合且需要更大的训练数据集。

#### 6.4 机器学习引导的逆向材料设计

新材料的设计需要识别可能的元素混合以产生目标材料性能，这本质上是一个逆向设计过程 [248-251],[252,253,194,254]。论文提供了一个基于微观结构图像的神经网络逆向设计解决方案 (图 12a)。输入是微观结构图像和实验测量的力学性能。神经网络模型由编码器、解码器和回归模型三个子模型组成。回归模型的结构和优化参数被复制来构建设计器，设计器具有反转的信息流，实现了从目标性能到合金成分的逆向设计。

ML 在材料科学中的另一个重要应用是对 XRD、TEM、SEM 和 APT 等科学图像的自动分析 [255]。Li 等人 [256] 使用 CNN 在 APT 数据中识别 L12 型有序纳米结构。Kaufmann 等人 [257] 使用 ResNet50 和 Xception 进行 EBSD 图样的晶体结构自主识别，准确率超过 90%。Ragone 等人 [258] 使用 FCNN 从 STEM 图像确定原子位置。Ma 等人 [259] 采用数据增强技术缓解小数据规模问题。

### 7. 结论

ML 与材料科学的协同促进了这个蓬勃发展且令人兴奋的领域的形成。高熵合金由于其优越的力学性能、广阔的成分空间和复杂的化学交互作用，是展示 ML 力量的特别有趣的候选者。

一方面，ML 方法可用于构建原子相互作用模型 (AIMs) 来描述多组元合金中的复杂交互作用，避免耗时的第一性原理热力学模拟。已提出一系列 ML AIMs [61,64]，包括 HDNNP、GAP、SNAP、MTP、LRP、贝叶斯 CE，使近 DFT 精度的模拟在传统方法无法达到的长度和时间尺度上成为可能 [63,62]。

另一方面，ML 也可用于构建体性质模型 (BPMs)，采用 NN、SVM、GP 和 CART 等方法。ML 模型在预测 HEAs 的相形成和力学性能方面展示了优异的性能 (表 3、表 4)，并已被应用于指导 HEAs 设计 [84,184]。

最后，有前途的研究方向包括 ML 模型的不确定性量化、端到端描述符和 ML 辅助的材料逆向设计。采用 ML 方法研究高熵合金预计将继续快速扩展，许多机遇等待进一步探索。
