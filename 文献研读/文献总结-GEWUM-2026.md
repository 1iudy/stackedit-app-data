## 三、论文内容的结构化总结

### 3.1 研究问题与目标

论文针对材料计算工具彼此割裂的问题展开。现有工具往往分别擅长结构生成、单点性质计算或某一类稳定性分析，但研究者仍需手动拼接结构采样、结构多样性筛选、几何弛豫、凸包分析和声子计算等步骤。论文特别指出，许多工作流没有原生集成 SLURM，因此难以将基于通用机器学习原子间势的计算从少量候选结构扩展到复杂化学空间中的数千个结构。

GEWUM 的目标不是仅提供一个结构预测器，而是把结构生成、多样性保持的候选筛选、uMLIP 驱动的结构弛豫、热力学稳定性和动力学稳定性验证，以及若干材料性质计算统一起来，并通过 SLURM 和节点内并行支持高通量计算。

### 3.2 核心方法链

论文将 Selective Random Structure Search，SRSS，嵌入 GEWUM。其主流程是：

1. 在目标化学组成和维度约束下，按对称性生成随机结构。
2. 用结构特征描述符和 K-means 或 HDBSCAN 聚类进行多样性保持的结构选择。
3. 使用 uMLIP 对候选结构进行几何弛豫。
4. 相对于 Materials Project 中已有结构计算凸包能量，评估热力学稳定性。
5. 通过声子色散分析检查动力学稳定性，并排除含虚频的结构。
6. 对保留下来的候选结构进行弹性、准谐近似、热导率和分子动力学等性质计算。

对于 3D 晶体，平台支持 230 个空间群的结构生成；对于低维体系，论文列出 80 个层群、75 个杆群和 32 个点群。2D 材料还可自动分为中心对称和非中心对称类别，3D 结构则可进行空间群对称化和可选的手性识别。

### 3.3 软件架构与工程设计

GEWUM 采用四层架构：命令行界面、工作流命令层、脚本仓库层和计算后端层。命令行层提供 RD、PT、ELA、QHA、TC、MD 和 DB 等工作流命令；命令层以 `BaseWorkflowCommand` 为基类，统一处理参数解析、文件仓库、模板渲染和 SLURM 配置；脚本仓库按工作流组织，并由公共模块提供结构弛豫、结构选择、声子、能量凸包和对称性分析；后端集成预训练通用机器学习力场、PyXtal、Phonopy、Phono3py 和 ASE。

平台的三个设计原则是统一接口、灵活部署和模板驱动配置。用户可以复制计算脚本进行本地修改和调试；`slurm_config.yaml` 中的集群参数通过占位符替换写入每个工作流脚本，从而减少不同脚本之间的配置漂移。

### 3.4 并行与容错

平台采用两级并行。外层通过 SLURM 模板提交不同工作流；内层在单个计算节点上使用 Python `multiprocessing.Pool` 或 GNU Parallel。并发度由 `SLURM_CPUS_PER_TASK` 自动推断。

结构生成按对称群并行；结构弛豫将未处理的 CIF 文件组织为任务队列，自动跳过已经完成的结构；结构多样性选择可以并行处理多个对称群子目录。批处理脚本具有幂等任务过滤机制，因此节点故障或超时后可以安全重新提交而不重复计算。

### 3.5 四个案例的主要结果

- Al-Sc-N：对 $(\mathrm{Al}_{13}\mathrm{ScN}_{16})_x$，$x=1,2$，进行随机结构生成、uMLIP 快速弛豫、凸包能筛选和 PBE 精修。理论上可尝试 $229 \times 100 \times 2=45{,}800$ 个结构，受 64 原子上限和 Wyckoff 位点约束影响，实际生成 13,200 个候选结构。最终候选的相对焓约为 $0$--$0.31\ \mathrm{eV/atom}$，其中 $Cm$-1 结构为基态候选；$P$-1-3、$P$-1-12 和 $P$-1-11 也处于低能区域。
- $\mathrm{U}_3\mathrm{Si}_5$：论文报告通过 RD 模块预测出 $P\bar{6}2c$ 结构，并将其与已知的 AlB$_2$ 型结构区分。作者使用 PBE+$U$，$U_{\mathrm{eff}}=4\ \mathrm{eV}$，进行进一步优化，并通过模拟 XRD 和 500 K 的 AIMD 对结构模型进行补充验证。
- $\mathrm{ThH}_{10}$：在 150 GPa 下，每个空间群尝试 200 个结构，共 45,800 次尝试，得到 29,400 个有效初始结构；正文不同段落对用于压缩的有效结构数分别出现 29,400 和 26,400 的表述，本文保留论文原文这一数值差异，不自行修正。候选压缩至 5,280 个，优化约 4 h，随后提取 10 个低焓候选。声子计算显示若干结构具有虚频，而文献报道的 $Fm\bar{3}m$-$\mathrm{ThH}_{10}$ 具有更好的动力学稳定性。
- 热物性验证：立方 SiC 的晶格热导率在 300--1700 K 随温度单调下降；对 $\mathrm{U}_3\mathrm{Si}_2$，MatterSim-1M、MatterSim-5M 和 DPA3-OMat24 给出了大体一致的温度趋势，但绝对值和各向异性存在明显差别。$\mathrm{U}_3\mathrm{Si}_2$ 的体积热膨胀系数随温度增加，并在数量级与温度依赖上总体符合实验趋势。热物性模块的典型耗时约为单节点每个结构 3--30 min。

### 3.6 论文的适用边界

正文明确指出，完整工作流需要基于 SLURM 的 HPC 环境；uMLIP 驱动的结构弛豫和性质计算还需要安装相应的可选 uMLIP 后端。作者强调 GEWUM 并非要取代成熟的自动化材料模拟平台，而是作为一个易用的辅助平台，降低初学者使用 MLP 完成结构生成、计算、筛选、分析和可视化的门槛。

### 摘要（Abstract）

现有计算工具彼此割裂的格局，常常阻碍大规模结构预测与严格稳定性验证之间的无缝整合。为解决这一问题，我们提出 GEWUM（General Exploration Workflow for the Utopia of Materials，材料乌托邦的通用探索工作流），这是一个开源平台，将选择性随机结构搜索（Selective Random Structure Search，SRSS）策略与通用机器学习原子间势（universal Machine Learning Interatomic Potentials，uMLIPs）相结合，从而实现材料发现的自动化与加速。GEWUM 原生支持基于 SLURM 的高性能计算集群，将从结构生成、多样性保持的筛选，到热力学/动力学稳定性评估和性质计算的完整工作流统一起来。该平台还集成了内置可视化工具，包括用于空间群演化的 Sankey 图、用于能量分布的小提琴图，以及用于结构多样性分析的 t-SNE/UMAP 嵌入，从而便于直观解释筛选结果。我们通过三个案例展示 GEWUM：Al-Sc-N 中的低能多晶型预测、$P\bar{6}2c$-$\mathrm{U}_3\mathrm{Si}_5$ 相的识别，以及 150 GPa 下 $\mathrm{ThH}_{10}$ 的高压结构预测。基准测试表明，平台对热物理性质的预测具有合理的一致性。

### 1. 引言（Introduction）

长期以来，对具有定制性质的新材料的探索一直受到能源、电子学和可持续性等全球性挑战的需求驱动 [1-4]。近年来，随着通用机器学习原子间势（uMLIPs）的出现，计算材料科学的格局发生了范式转变 [5-9]。与传统经验势不同，预训练的 uMLIP 现在能够以远低于密度泛函理论（DFT）的计算成本，提供接近 DFT 的精度，从而实现对巨大化学空间的快速探索 [10-12]。因此，利用这些先进势函数同时进行晶体结构预测（CSP）和后续性质评估，已经成为现代材料发现中的主流策略 [13-19]。

然而，尽管 uMLIP 算法已经成熟，也存在能够处理不同维度的多种 CSP 代码——从 0D 分子到 3D 晶体——要充分利用这一潜力，仍然缺少关键的软件基础设施 [20-25]。目前，研究者面对的是一个彼此割裂的生态系统：单个工具可能擅长结构生成或单点性质计算，但能够将完整工作流无缝整合起来的统一、用户友好型平台仍然明显不足 [26-29]。值得注意的是，AFLOW 以及 MaterialsAtlas.org 提供的在线工具 [30-33] 可以组合成将结构生成与性质评估耦合起来的工作流，这些工作对工作流集成作出了有价值的贡献。尽管如此，这些平台主要侧重高通量筛选或数据库驱动的工作流，目前尚未提供一个以 uMLIP 为原生核心、带有内置 HPC 编排能力的统一晶体结构预测框架。

具体而言，现有方法通常要求用户手动拼接结构采样、多样性筛选和严格稳定性验证的不同脚本，例如凸包分析和声子计算。更重要的是，大多数框架缺少与 SLURM 等高性能计算工作负载管理器的原生集成。内置并行化能力的缺失，使得将基于 uMLIP 的工作流从少量候选扩展到复杂化学空间中的数千个结构变得极其困难，从而抑制了机器学习所承诺的效率提升。

为弥合这一差距，并为材料界提供一种易于采用且高效的工具，我们提出统一平台 GEWUM。GEWUM 的设计目标不只是结构预测器，而是一个全面的端到端软件平台，用于最大限度地发挥 uMLIP 在大规模科学研究中的作用。GEWUM 将近期提出的选择性随机结构搜索（SRSS）策略 [34] 嵌入一个稳健的工程框架，消除了手动管理脚本的需要，并为从初始假设到经过验证的材料候选提供了简化路径。

GEWUM 的核心优势在于整体集成、以用户为中心的设计和可扩展性。首先，它统一了完整的发现流程：软件自动处理与维度无关的结构生成、自适应多样性筛选，以及关键的热力学和动力学稳定性评估。这种“预测-验证”架构确保用户获得物理上可实现的候选结构，而不必承担彼此割裂的后处理步骤。其次，也是最重要的一点，GEWUM 通过简化的配置机制实现了与 SLURM 集群的无缝集成。用户只需修改一个模板文件，就可以在整个工作流中启用大规模并行，从结构弛豫到性质计算均可如此。该设计抽象掉作业提交脚本、资源分配和依赖管理的复杂性，使研究者无需专门的 HPC 技能即可轻松利用数百或数千个 CPU 核心。最后，GEWUM 通过模块化命令行界面和针对复杂性质的预配置模板来优先保障可访问性，例如弹性常数、热导率和准谐近似，使科学家能够专注于物理洞见，而不是计算细节。

本文详细介绍 GEWUM 的架构和能力，并通过不同体系中此前未知多晶型的发现展示其有效性。通过结合 SRSS 的无偏探索能力、uMLIP 的速度与精度，以及 SLURM 集成所带来的易扩展性，GEWUM 为高效、全面且用户友好的材料发现建立了新的标准，并有效释放机器学习势函数面向更广泛科学群体的潜力。

### 2. 方法与软件实现：软件设计和实现（Software design and implementation）

#### 2.1 软件架构

##### 2.1.1 设计理念

GEWUM 采用模块化设计理念，将复杂的材料计算工作流分解为彼此独立但可以组合的功能模块。架构设计遵循三个核心原则：统一接口、灵活部署和模板驱动配置。统一接口原则确保所有工作流都可以通过一致的命令行范式访问，即 `gewum <command> -mode <mode>`，这显著降低了用户的学习成本，并支持在不同计算模块之间无缝切换。灵活部署原则通过文件复制机制赋予用户对计算脚本的细粒度控制，使用户可以在不改变核心软件安装的情况下进行本地修改、调试和定制。模板驱动原则通过引入层级式 SLURM 配置系统解决不同计算环境适配的难题，在该系统中，部署相关参数会通过占位符替换自动注入计算脚本。

##### 2.1.2 系统架构

GEWUM 平台采用四层层级系统，将用户交互、工作流编排、脚本管理和计算执行清晰分离。客户端使用工作流如图 1(a) 所示。命令行界面构成最上层，也是用户交互的主要界面。它通过一致的语法范式提供 7 个主要工作流命令：RD、PT、ELA、QHA、TC、MD 和 DB。其下是工作流命令层，该层以基类 `BaseWorkflowCommand` 为中心，实现面向对象的命令分派系统。该层封装参数解析、文件仓库管理和 SLURM 模板处理等公共功能，而 `RDCommand`、`PTCommand` 等具体实现负责工作流特定逻辑。脚本仓库层是系统的功能骨干，将计算脚本组织到面向工作流的目录中，如 `RDworkflows`、`PTworkflows`，并在 `common` 目录下放置共享功能模块。共享模块包括结构弛豫、多维结构选择、声子计算、能量凸包分析和后处理对称性分析等关键功能。位于最底层的计算后端集成外部科学计算库和机器学习框架，内置预训练通用机器学习力场计算；PyXtal 用于受对称性约束的晶体生成 [35]，Phonopy 和 Phono3py 用于晶格动力学与热输运 [36]，ASE 则充当统一的原子模拟环境接口 [37]。主页截图见图 1(b)。

##### 2.1.3 核心组件

GEWUM 的架构完整性依赖多个共同确保系统可靠性、可扩展性和用户友好性的核心组件。`main.py` 中实现的命令分派器是平台的中枢，通过自省动态加载工作流模块，组织参数验证与解析，并提供统一的错误处理和日志功能。`BaseWorkflowCommand` 类为所有工作流实现建立接口，定义脚本发现、模板渲染和文件部署等标准方法，同时抽象出 SLURM 配置集成的复杂性。模板工具模块 `template_utils.py` 实现配置解析逻辑，在多个层级中搜索用户定义的设置，包括工作目录、安装目录和内置默认值，并自动生成带有适当资源分配指令和环境设置命令的 SLURM 头部代码。配置管理器 `config.py` 集中管理路径，并维护工作流命令与关联脚本仓库之间的确定性映射，从而确保不同部署场景下的文件解析保持一致。这些组件共同形成了一个连贯的架构基础，在抽象性与灵活性之间取得平衡，使新工作流模块能够快速开发，同时保持 GEWUM 用户体验所要求的运行一致性。

#### 2.2 核心功能

##### 2.2.1 随机设计工作流（RD）

GEWUM 的一项主要能力是实现 SRSS 框架，用于晶体结构生成和筛选，见图 1(c)。该方法通过受对称性约束的随机生成探索构型空间，涵盖 230 个空间群、80 个层群、75 个杆群和 32 个点群；随后利用基于特征的多样性选择，可采用 K-means [38] 聚类或基于密度的 HDBSCAN [39] 聚类。用户也可以跳过选择步骤，直接优化全部结构。所选候选结构使用 uMLIP 进行高通量几何弛豫。SRSS 框架采用双重过滤的稳定性评估机制：一方面，通过相对于 Materials Project 数据库中已有结构计算凸包能量来评估热力学稳定性 [40]；另一方面，通过声子色散分析验证动力学稳定性，并自动排除出现虚频的结构。对于 2D 材料，平台提供层群对称性分类，并自动分为中心对称和非中心对称类别；对于 3D 结构，则进行空间群对称化，并可选择进行手性识别。因此，GEWUM 可以识别从块体晶体到低维纳米材料等各种周期维度下的稳定和亚稳结构，而只需要标准计算资源。

##### 2.2.2 扰动工作流（PT）

扰动工作流支持从已知晶体构型出发系统探索结构相空间，可用于相变研究、掺杂工程和成分替代筛选等多种材料工程任务。该模块实现了 4 种不同的结构生成范式：其一是超胞生成，用于研究有限尺寸效应，并通过有控制地扩展晶胞尺寸来构造缺陷模型；其二是基于元素替代，根据 YAML 配置文件中用户定义的替代规则，系统探索等价和异价替代；其三是结构突变，通过对原子位置施加受控随机位移并引入晶格应变扰动，帮助结构逃离局部能量极小并探索势能面的邻近区域；其四是掺杂工程，通过浓度控制的随机替换，将主体原子替换为掺杂物种，自动生成多个掺杂构型，同时保持总体电荷中性。PT 工作流的一个关键架构特征是与 RD 工作流筛选输出的无缝互操作性：通过 RD 筛选识别出的结构可以直接进入 PT 流程，进行高通量元素扩展和结构探索，从而最大限度地发现多样化的化学构型。PT 模块的工作流见补充材料。

##### 2.2.3 性质计算

GEWUM 集成了一组全面的性质计算模块（ELA、QHA、TC、MD），这些模块通过 ASE 的统一 Calculator 接口使用 uMLIP，从而无需传统 DFT 的计算成本即可高效表征力学、热学和热力学性质。弹性分析（ELA）模块通过与 Vaspkit 变形分析工具集成，实现能量-应变方法：根据施加应变后的应力响应计算完整弹性常数张量，并进一步得到体积模量、剪切模量、杨氏模量和泊松比；该模块同时支持小应变和有限应变计算模式。晶格动力学与热输运能力由热导率（TC）模块提供，该模块将 uMLIP 力评估与 Phonopy、Phono3py 相结合，计算声子色散关系、态密度，以及通过弛豫时间近似下的玻尔兹曼输运方程得到的温度依赖晶格热导率。准谐近似（QHA）模块自动在一系列晶格膨胀点上进行体积依赖的自由能计算，从而预测热膨胀系数和温度依赖热容。分子动力学（MD）模块提供带 Langevin 恒温器的 NVT 系综模拟，用于评估高温动力学稳定性，并生成能量-时间演化轨迹和温度波动统计，以分析结构退化。这些性质计算模块通过 ASE Calculator 接口共享统一计算后端，确保力评估的一致性，并与 SRSS 工作流无缝集成，实现全面的材料表征。此外，数据库（DB）模块提供一个只读接口，用于检查和管理 `structures.db` 内容。该模块支持查询元数据、开展多维统计分析，以及依据化学或能量标准筛选结构；它还支持将指定或筛选出的 CIF 文件批量导出到本地目录或 ZIP 压缩包，而不会修改底层数据库。

#### 2.3 并行执行与容错

##### 2.3.1 两级并行架构

GEWUM 采用层级式两级并行架构，以最大化分布式 HPC 环境中的计算吞吐量。在外层，所有工作流通过模板化提交脚本原生集成 SLURM 作业调度器，资源分配指令由统一的 `slurm_config.yaml` 配置文件动态参数化。这种设计使 GEWUM 能够在异构 HPC 集群上无缝部署，而不需要手动修改各个工作流脚本。在内层，CPU 密集型计算任务使用 Python 的 `multiprocessing.Pool` 或 GNU Parallel [41-45]，在单个计算节点的所有可用核心上并行执行；并发程度根据 `SLURM_CPUS_PER_TASK` 环境变量自动推断，以确保资源得到充分利用。

##### 2.3.2 面向工作流的并行策略

平台针对每个工作流阶段的计算特征实现了专门的并行策略。使用 `cif_generate.py` 进行结构生成时，在对称群层面利用并行，将任务分配给所有目标对称群，并通过 `multiprocessing.Pool.map()` 实现随可用 CPU 数量接近线性的扩展。结构弛豫采用任务队列范式：将所有未处理 CIF 文件列举为扁平任务列表，自动检测并跳过已经弛豫的结构，以支持容错重启；随后由 GNU Parallel 分派并发弛豫任务，确保分配的计算资源得到充分利用。结构多样性选择模块可以并发处理多个对称群子目录，支持从 0D 到 3D 的所有维度以及多种描述符-聚类组合，同时保持吞吐量。

##### 2.3.3 容错与配置管理

为适应高通量计算任务的规模，所有批处理脚本都包含幂等任务过滤机制，可以检测并跳过先前已经处理的结构。这一设计使节点故障或达到墙钟时间限制后能够安全重新提交，而不会产生重复计算。此外，所有 SLURM 参数，包括分区选择、CPU 分配、墙钟时间限制、conda 环境激活和模块加载顺序，都集中在 `slurm_config.yaml` 中管理，并通过模板替换引擎在脚本生成时注入每个工作流脚本。这种集中式配置方法消除了逐脚本配置漂移，用户只需修改一个文件即可使整个 GEWUM 套件适配不同 HPC 环境。

#### 2.4 关键输入文件

GEWUM 依靠一组简洁的面向用户的输入文件控制所有模块中的工作流行为。主配置文件 `slurm_config.yaml` 集中保存所有 HPC 环境参数，包括 SLURM 资源指令、模块加载顺序和 conda 环境路径；在新计算集群上部署 GEWUM 时，该文件是唯一需要适配的入口。对于结构生成，`chem_input.inp` 以轻量级逐行格式规定目标化学组成和化学计量比，软件据此自动生成中间文件 `cifgen.inp`，供后续结构生成使用。PT 工作流还使用两个 YAML 格式的配置文件 [46-49]：`replacements.yaml` 定义元素替代规则，用于系统的成分探索；`doping.yaml` 指定掺杂物种、主体元素、替代浓度和待生成的掺杂构型数量。这些文件共同构成 GEWUM 完整的用户配置层。设计上有意减少配置文件数量，以降低日常使用门槛，同时保留足够的高级定制能力。

### 3. 结果与案例（Examples）

#### 3.1 案例 1：Al-Sc-N 体系的结构预测

纤锌矿 Al-Sc-N 体系因其在压电、铁电和功能薄膜材料中的潜在应用而受到广泛关注 [50-53]。为评估 GEWUM 在复杂多组分氮化物体系结构预测中的能力，我们选取 $(\mathrm{Al}_{13}\mathrm{ScN}_{16})_x$，其中 $x=1,2$，作为模型体系。总体计算工作流见图 2(a)。

**步骤 1：候选结构预测。** 在 GEWUM 中，用户只需指定目标化学组成和维度，软件便会自动构造满足组成约束的候选晶体结构。对于目标组成，输入 `chemi_input` 格式为：

```text
Al = 13
Sc = 3
N = 16
```

晶胞最大原子数设置为 64。原则上，这些目标组成允许生成 $229\times100\times2=45{,}800$ 个随机结构。然而，由于对生成结构施加了 64 原子的最大限制，并且某些空间群在目标化学计量、原子数和 Wyckoff 位点限制同时存在时无法生成试探结构，实际得到的候选结构数量为 13,200。使用命令 `gewum RD -mode cifgen`，随后修改 `cifge.sh` 中的相关参数并提交到 SLURM 集群，即可进行高通量晶体结构生成。

**步骤 2：使用机器学习势快速弛豫。** GEWUM 使用预训练 uMLIP 机器学习势进行高通量几何优化。使用命令 `gewum RD -mode relax`，随后修改 `relax_umlip.sh` 中的相关参数并提交集群，即可进行高通量结构优化。

**步骤 3：保持多样性并筛选低能结构。** 结构弛豫完成后，进一步评估每个构型的凸包能量 $E_{\mathrm{hull}}$，并根据 $E_{\mathrm{hull}}$ 对结构排序。随后保留能量最低的 50 个候选结构，进入下一阶段计算。使用命令 `gewum RD -mode post` 和 `gewum RD -mode Ehull`。

**步骤 4：DFT 精修与最终能量排序。** 对前一步选出的 50 个低能候选结构，首先在 PBE 水平进行第一性原理计算。完全结构弛豫之后，重新计算并排序所有保留构型的相对能量。如图 2(b) 所示，最终候选结构的相对焓分布约为 $0$--$0.31\ \mathrm{eV/atom}$。其中，$Cm$-1 结构成为基态构型；此外，$P$-1-3、$P$-1-12 和 $P$-1-11 等多个结构也位于低能区域，其晶体结构示意图见图 2(c)。

图 2(d) 和图 2(e) 进一步展示了 GEWUM 内置于 SRSS 工作流中的统计可视化能力。图 2(d) 给出 Sankey 图，显示结构从初始空间群到结构弛豫后空间群的演化，并进一步将弛豫结构连接到各自的凸包能量 $E_{\mathrm{hull}}$ 分布。该可视化直观表示了结构优化过程中可能发生的对称性演化，以及不同结构的能量稳定性。图 2(e) 使用小提琴图展示按空间群分组的弛豫结构能量分布，便于比较不同结构对称性对应的能量范围、分布宽度和相对集中程度。这些可视化工具使用户能够直接检查结构预测结果中的空间群演化、结构数量和能量分布等统计信息，从而有助于识别具有代表性的低能结构和潜在稳定结构类型。

这些结果表明，Al-Sc-N 体系具有非常丰富的构型景观。这一特征对于阐明 Al-Sc-N 基功能材料中的相竞争、识别可行的合成路径，以及明确结构与性质之间的后续关系具有重要意义。

#### 3.2 案例 2：寻找 $\mathrm{U}_3\mathrm{Si}_5$ 的未知同素异形体

长期以来，$\mathrm{U}_3\mathrm{Si}_5$ 的晶体结构被广泛认为是六方的 $\beta$-ThSi$_2$ 型或 AlB$_2$ 型结构（空间群 $P6/mmm$）[54]。换言之，该结构可以描述为 USi$_2$ 的 $3\times1\times1$ 超胞中包含一个单个位点硅空位的缺陷构型，如图 3(e) 所示。然而，近期实验已经证实，$\mathrm{U}_3\mathrm{Si}_5$ 实际上存在两个热力学稳定相。这表明，除了 AlB$_2$ 型结构之外，还存在一个未知晶体构型 [55]。

图 3(a)-(d) 进一步展示了 GEWUM 中结构选择和优化过程的低维可视化。图 3(a) 比较了初始生成结构、筛选结构和弛豫结构在低维 t-SNE 空间中的分布。初始生成结构在特征空间中呈现宽广且相对均匀的分布，而筛选结构仍然能够覆盖原始结构空间。这说明，选择过程在显著减少候选结构数量的同时，并没有明显损害结构采样的多样性。图 3(b)-(d) 分别展示初始生成结构、筛选结构和弛豫结构在 t-SNE 空间中的密度分布。初始生成结构和筛选结构的总体分布特征保持相似，进一步表明该选择策略在降低后续计算成本的同时保留了结构空间的代表性采样。相比之下，结构优化之后，低维特征空间中的总体分布和局部聚类特征都发生了显著改变，说明结构弛豫会导致原子构型和局域结构环境发生实质性重排。因此，充分的结构优化是结构预测工作流中的必要步骤，对于获得具有物理意义的候选结构并可靠评估其后续稳定性具有重要作用。

基于 GEWUM 软件的 RD 模块，本研究成功预测了 $P\bar{6}2c$-$\mathrm{U}_3\mathrm{Si}_5$ 结构，如图 3(f) 所示。该结构属于六方晶系：U 原子沿 $c$ 轴方向周期性排列成层，并均匀嵌入由 Si 原子在 $ab$ 平面内形成的连续共价骨架中。该结构由较弱的 U-Si 相互作用稳定，体现出 U 的金属性和 Si 的共价性质共存。在 $ab$ 平面内，Si 原子通过强共价键形成扭曲的 12 元环网络；这一共价环是材料机械强度、热稳定性和优异抗辐照性能的关键来源。

表 1 显示，$P\bar{6}2c$-$\mathrm{U}_3\mathrm{Si}_5$ 的晶格参数 $c=4.258\ \mathrm{\mathring{A}}$，与理论计算的 AlB$_2$ 型 $\mathrm{U}_3\mathrm{Si}_5$ 值 $3.947\ \mathrm{\mathring{A}}$ 存在显著差异。考虑到 U 基体系中 5f 电子的强关联效应，我们进一步使用 DFT+$U$ 方法对两种结构进行结构精修和优化，其中有效关联能 $U_{\mathrm{eff}}=4\ \mathrm{eV}$。结果表明，在加入 $U_{\mathrm{eff}}$ 修正后，两种结构的晶格参数与实验测量值的符合程度均显著改善。然而，$P\bar{6}2c$-$\mathrm{U}_3\mathrm{Si}_5$ 的晶格参数相对于实验测得的 AlB$_2$ 型 $\mathrm{U}_3\mathrm{Si}_5$ 仍存在不可忽略的系统偏差，因此有力地确认这两种结构是晶体学上根本不同的相。

为了进一步验证本研究识别出的 $P\bar{6}2c$-$\mathrm{U}_3\mathrm{Si}_5$ 结构是区别于 AlB$_2$ 型的全新晶体构型，我们使用 VESTA 软件的 XRD 模拟功能 [56]，对两种结构的衍射图谱进行模拟分析，结果见图 3(g)。两种 $\mathrm{U}_3\mathrm{Si}_5$ 结构模拟 XRD 图谱中特征峰的相对位置总体上与实验测量结果一致 [57]。此外，已有实验报道证实，在 Er$_3$Si$_5$ 和 Yb$_3$Si$_5$ 等镧系硅化物中存在扭曲的 12 元硅环结构 [58,59]。这一特征与本研究预测的新结构一致，为该结构模型的合理性提供了额外证据。此外，本研究采用从头算分子动力学（AIMD）模拟，在 500 K 下验证扭曲 12 元硅环的热稳定性（图 3(h)）。通过比较移除铀原子后扭曲 12 元硅环的结构演化，我们确认所预测的 $P\bar{6}2c$-$\mathrm{U}_3\mathrm{Si}_5$ 结构表现出优异的高温结构稳定性。

#### 3.3 案例 3：通过 SRSS 在 150 GPa 下预测 $\mathrm{ThH}_{10}$ 晶体结构

为展示 GEWUM 对固定组成高压氢化物体系结构预测的能力，我们以 150 GPa 下的三维 $\mathrm{ThH}_{10}$ [60] 为代表性测试案例。本例用于评估代码在极端压力条件下的大规模结构生成、快速筛选和稳定性识别能力。与案例 1 不同，本例使用 SRSS 方法显著减少优化过程中的结构数量。SRSS 方法的详细过程见文献 [34]。

**步骤 1：候选结构生成。** 对每个空间群生成 200 个试探结构，共进行 45,800 次尝试，最终获得 29,400 个有效初始结构。整个过程在单个 64 核 CPU 节点上只需要约 30 s。

**步骤 2：代表性结构提取与搜索空间压缩。** 为提高筛选效率并降低计算负担，GEWUM 提取结构特征描述符，并将其与机器学习聚类算法结合，以识别代表性构型，从而平衡搜索广度与后续优化成本。与 Al-Sc-N 体系使用 K-means 策略不同，$\mathrm{ThH}_{10}$ 案例中使用 HDBSCAN。对于每个空间群，保留代表性结构和噪声结构，将 26,400 个有效初始结构压缩为 5,280 个。此步骤只需要约 1 min。图 4(a) 中的 t-SNE 可视化显示，筛选后的结构在特征空间中仍然均匀分布，说明原始结构池的多样性得到良好保持。使用命令 `gewum RD -mode select`。

**步骤 3：高压结构优化与低焓候选筛选。** GEWUM 在 150 GPa 下对保留的 5,280 个候选结构进行高压结构优化。该步骤在单个 64 核 CPU 节点上约需 4 h。优化完成后，程序自动汇总收敛结构，按焓排序，并提取 10 个最低焓候选；这一后处理阶段仅需约 28 s。所得低焓集合包含多种对称性类别，包括 $F\bar{4}3m$、$P4_2 2_1 2$、$I4/mmm$、$Fm\bar{3}m$ 和 $P6_3/mmc$。

**步骤 4：动力学稳定性评估。** 我们进一步对 10 个筛选出的代表性结构进行声子谱计算；在一个 CPU 节点上完成全部声子计算约需 4 min。结果表明，$F\bar{4}3m$、$P4_2 2_1 2$、$I4/mmm$ 和 $P6_3/mmc$ 等结构在不同程度上呈现虚声子模，说明它们在 150 GPa 下动力学不稳定。相比之下，文献报道的 $Fm\bar{3}m$-$\mathrm{ThH}_{10}$ 相具有明显更好的动力学稳定性，如图 4(b)-(d) 所示。

#### 3.4 案例 4：热物理性质模块验证

为评估 GEWUM 进行热物理性质计算的适用性，我们对 TC 模块和 QHA 模块这两个代表性模块进行了基准测试。通过用机器学习原子间势替代计算成本高昂的力常数评估，并结合弛豫时间近似（RTA）等近似方案，GEWUM 能够快速评估热输运性质，从而建立适用于高通量筛选的热物理工作流。

以立方 SiC 为例，在 300--1700 K 温度范围内，计算得到的晶格热导率随温度升高而单调下降，与实验所显示的总体趋势一致 [61]。如图 5(a) 所示，这说明该模块能够合理捕捉高温下增强的声子散射对热导率的抑制作用。除此之外，对 $\mathrm{U}_3\mathrm{Si}_2$ 使用不同机器学习势得到的结果表明，MatterSim-1M [62]、MatterSim-5M [62] 和 DPA3-OMat24 [63] 给出了总体一致的温度依赖趋势，但在绝对大小和各向异性程度上存在明显差异。

这一结果说明，晶格热导率对底层机器学习势的准确性高度敏感，如图 5(b) 所示。除了热导率之外，GEWUM 还实现了基于机器学习势计算热膨胀系数和 Gibbs 自由能的模块。以 $\mathrm{U}_3\mathrm{Si}_2$ 为例（图 5(c)），体积热膨胀系数随温度单调增加，并且在数量级和温度依赖性方面总体符合参考实验数据，说明该模块能够充分表征材料的高温热力学响应。热物理模块的典型计算成本为单个 CPU 节点每个结构约 3--30 min，显著低于传统第一性原理热输运计算。因此，GEWUM 不仅支持结构搜索和稳定性评估，也可以扩展到热物理性质的自动化评估，为从候选结构到功能性质的材料发现提供连续计算框架。

必须强调，GEWUM 并不是为了取代现有成熟的自动化材料模拟平台。相反，在机器学习势快速发展的背景下，它旨在成为一个易于使用的计算材料科学辅助平台，尤其面向该领域的新入门者。除了集成 SRSS 晶体结构预测工作流之外，GEWUM 还提供一组基于 ASE 的工具，使用户能够方便地使用不同 uMLIP，完成从晶体结构预测到材料性质计算和分析的任务，例如热导率计算。GEWUM 的设计优先考虑工作流可用性，包括简化参数配置、计算阶段之间的无缝衔接，以及内置后处理和可视化工具。这些功能并非意在取代专门的模拟软件，而是降低在实际材料研究中应用 MLP 的门槛，使缺乏构建复杂工作流经验的用户也能够高效完成从结构生成和计算，到筛选、分析和可视化的基本流程。

### 4. 结论（Conclusion）

总之，我们开发了开源平台 GEWUM。通过将 uMLIP 与 SRSS 方法相结合，GEWUM 为自动结构预测和性质表征提供了稳健的端到端解决方案。除计算功能之外，平台还集成了一组可视化工具，例如用于追踪空间群演化的 Sankey 图、用于比较能量分布的小提琴图，以及用于监测结构多样性的 t-SNE/UMAP 投影。这些工具使用户无需外部后处理即可直接检查和解释大规模筛选任务的统计特征。我们通过 4 个案例展示了 GEWUM 的多功能性：三元 Al-Sc-N 体系中多晶型的发现、$P\bar{6}2c$-$\mathrm{U}_3\mathrm{Si}_5$ 相的识别、$\mathrm{ThH}_{10}$ 的高压预测，以及晶格热导率和热膨胀系数计算的验证。通过降低大规模计算筛选的门槛，GEWUM 为加速晶体结构预测和能源、可持续性应用中的功能材料发现提供了一条路径。

## 六、计算细节汇总

- Al-Sc-N 结构生成：目标为 $(\mathrm{Al}_{13}\mathrm{ScN}_{16})_x$，$x=1,2$；最大晶胞原子数 64；实际生成 13,200 个候选结构；保留 50 个低 $E_{\mathrm{hull}}$ 候选进行 PBE 精修。
- $\mathrm{U}_3\mathrm{Si}_5$：对预测的 $P\bar{6}2c$ 和 AlB$_2$ 型结构进行 PBE 与 PBE+$U$ 比较，其中 $U_{\mathrm{eff}}=4\ \mathrm{eV}$；模拟 XRD；对扭曲 12 元硅环进行 500 K AIMD 稳定性验证。
- $\mathrm{ThH}_{10}$：压力 150 GPa；每个空间群 200 次尝试；总尝试次数 45,800；有效结构、筛选结构、优化时间和声子计算时间按正文分别为 29,400/26,400、5,280、约 4 h、约 28 s 和约 4 min；使用 HDBSCAN 进行结构压缩和代表性结构提取。
- 热输运：SiC 温度范围 300--1700 K；采用 uMLIP 力评估、Phonopy/Phono3py 和 RTA；对 $\mathrm{U}_3\mathrm{Si}_2$ 比较 MatterSim-1M、MatterSim-5M 和 DPA3-OMat24。
- 资源：论文说明部分计算在配备 HYGON X86 32 核、2.5 GHz 处理器的 Sugon HPC 集群和北京超级云计算中心完成。

## 八、数据可用性声明的翻译

GEWUM 是开源 Python 软件包，可从 [https://github.com/JesseOOPP/GEWUM](https://github.com/JesseOOPP/GEWUM) 获取。该软件要求 Python >= 3.8，并依赖一组成熟的科学计算库，包括 NumPy、SciPy、pandas、matplotlib、ASE、pymatgen、PyXtal、spglib、Phonopy、Phono3py、scikit-learn 和 Materials Project API 客户端 `mp-api`。软件可以直接从源代码仓库以可编辑模式安装：

```bash
git clone https://github.com/JesseOOPP/GEWUM
cd gewum
pip install -e .
```

DPA3、SevenNet、MatterSim、MACE 或 UPET 等机器学习原子间势后端属于可选依赖，应根据用户的硬件环境和偏好进行安装。GEWUM 对 uMLIP 后端保持后端无关性，只要求其兼容 ASE Calculator 接口。当前稳定版本为 1.0.0。
